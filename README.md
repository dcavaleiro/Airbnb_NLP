# 🏠 Airbnb NLP: Predicting Listing Status Using Natural Language Processing

This project leverages Natural Language Processing (NLP) techniques to predict the status of Airbnb listings based on textual data. By analyzing descriptions and other textual attributes, the model aims to determine whether a listing is active, inactive, or has been removed.

## 📁 Repository Contents

- `NLP_06.ipynb`: Jupyter Notebook containing the data preprocessing, exploratory data analysis, model training, and evaluation steps.
- `README.md`: Project documentation.

## 🛠️ Technologies & Tools

- **Programming Language**: Python
- **Libraries**:
  - Data Handling: `pandas`, `numpy`
  - NLP: `nltk`, `scikit-learn`
  - Visualization: `matplotlib`, `seaborn`
- **Environment**: Jupyter Notebook

## 📊 Project Overview

The objective of this project is to utilize NLP techniques to predict the status of Airbnb listings. The process involves:

1. **Data Preprocessing**: Cleaning and preparing textual data for analysis.
2. **Feature Extraction**: Converting text into numerical features using techniques like TF-IDF.
3. **Model Training**: Implementing machine learning models to classify listing statuses.
4. **Evaluation**: Assessing model performance using appropriate metrics.
